# Änderungsvorschläge

Hier liegen Änderungen an `formwert_app.html` als ALT/NEU-Blöcke, eine Datei
je Änderung, benannt `JJJJ-MM-TT-kurzer-name.md`.

Den genauen Aufbau beschreibt `AGENTS.md` im Hauptordner.

Angewendete Änderungen bleiben hier liegen – sie sind das Protokoll, was wann
warum geändert wurde.
