# Formwert

Trainings-App in Vanilla JavaScript, ohne Build und ohne Server. Läuft als Claude-Artifact:
https://claude.ai/artifact/2VEGYVStFNcZbz8fUsgXg5

**Wer hier arbeitet, liest zuerst [`AGENTS.md`](AGENTS.md).** Dort steht, wo was liegt und wie
gearbeitet wird.

## Ordner

| Ordner / Datei | Inhalt |
|---|---|
| `app/` | Die App, genau der Live-Stand |
| `VERSION` | Zuletzt veröffentlichte Version |
| `tests/` | Automatische Tests, laufen bei jedem Push |
| `wissen/` | Fachwissen und Entscheidungen (Übungstechnik, Design, Werkzeuge, Videos) |
| `werkzeug/` | Skripte: 3D-Modell und Animation aus- und einpacken, Patches übertragen, Messen |
| `patches/` | Änderungsvorschläge als ALT/NEU-Blöcke (von Assistenten ohne Repo-Zugriff) |
| `muskelmodell_3d_vollstaendig.html` | Ausgepackter 3D-Betrachter zum Bearbeiten (siehe `AGENTS.md` Abschnitt 5) |
| `PLAN-app-veroeffentlichen.md` | Weg zum App Store |
| `archiv/` | Alte Einzeldatei (Version 267) samt Lesefassung und Skripten. Nicht mehr verwenden. |

Offene Aufgaben stehen nicht im Repo, sondern im To-Do-Artifact „Formwert Offene Punkte“:
https://claude.ai/artifact/VKH7jhzqZusa8JakMewBAs
